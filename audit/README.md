# כלי ביקורת וחילוץ

הסקריפטים בתיקייה זו בודקים את מבנה קובצי DOCX ומחלצים חלונות טקסט לביקורת. הם אמורים לפעול בקריאה בלבד ביחס למסמכי המקור.

- חלונות ביקורת נכתבים אל review-windows/.
- מקורות DOCX היסטוריים נקראים מתוך archive/docx/.
- המחלץ העדכני P03696 קורא את המסמך המצטבר הפעיל שבשורש.
- inspect_docx.py מפיק דוח אל editorial-reports/word-comment-logs/ ומעדכן את יומן ההמשכיות ב־project-management/.
- אין להוסיף נתיב קובץ חדש בלי לעדכן גם את workflow המתאים ולוודא שהקובץ קיים.
