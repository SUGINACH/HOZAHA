# כלי הטמעת ותיקון הערות Word

- append_review_comments.py מטמיע הערות חדשות על בסיס אצווה מוגדרת ב־review_batches/.
- replace_review_comments.py מתקן רק הערות שמזוהות במפורש בקובץ תיקונים.
- נתיבי בסיס, פלט, דוח ויומן נקבעים בקובץ האצווה; יש להקפיד על נתיבים מלאים לאחר ארגון הארכיון.
- המסמך המצטבר הפעיל נשאר בשורש. מסמכי בסיס היסטוריים נקראים מתוך archive/docx/.
- אין להריץ אצווה שכבר הופקה בלי לוודא מראש שהפלט אינו קיים ושלא תיווצר כפילות.
