# סקריפטים היסטוריים ותשתיתיים

תיקייה זו כוללת סקריפטים ששימשו לבניית מסמכי Word היסטוריים, שחזור הערות והטמעת הערות סשן. תוצריהם נשמרו בארכיון.

תהליך rebuild-review-docx.yml הושבת במכוון לאחר העברת תוצריו לארכיון, כדי למנוע בנייה חוזרת או דריסה של מסמכים היסטוריים. אין להפעילו מחדש בלי הוראה מפורשת, בדיקת קובצי המקור והגדרת פלט חדש.
