# הגדרות אצוות הערות ותיקונים

קובצי JSON בתיקייה זו מגדירים את הערות Word, עוגניהן, מסמך הבסיס, מסמך הפלט, דוח ויומן ההמשכיות.

## כללי נתיבים
- מסמך בסיס היסטורי: archive/docx/שם-הקובץ.docx.
- מסמך מצטבר חדש: שם-הקובץ.docx בשורש.
- דוח: editorial-reports/word-comment-logs/.
- יומן: project-management/יומן-דחיפות-והמשכיות.md.

לפני הפעלת אצווה יש לוודא את מספר הפסקאות, מספר ההערות הקיימות, גיבוב גוף כתב היד, עוגנים ייחודיים, ואת העובדה שקובץ הפלט עדיין אינו קיים. קובצי אצווה היסטוריים נשמרים לצורכי תיעוד ואין להריצם מחדש ללא בדיקה.
