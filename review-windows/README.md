# חלונות ביקורת

תיקייה זו מכילה חלונות טקסט שחולצו מתוך כתב היד לצורך ביקורת לפי טווחי פסקאות. החלונות הם חומרי עבודה לקריאה בלבד; יש להפיק חלון חדש מתוך המסמך המצטבר המאומת ולא להניח שקובץ ישן הוא נקודת ההמשך העדכנית.

- כאשר חלון ביקורת כולל פסקאות שכבר נוספו להן הערות במסמך המצטבר הפעיל, יש לחלץ אותו מן המסמך שבשורש ולא מעותק ארכיוני שקדם להערות אלה. יש לוודא שמספר ההערות בחלון תואם למקור העדכני, ולשמור את גיבוב גוף כתב־היד.
